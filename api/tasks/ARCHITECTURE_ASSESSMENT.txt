CRITICAL GAPS:
──────────────
  ❌ NO EXCLUSIVE LOCK on task during user engagement
     Problem: Multiple users can attempt task simultaneously
     Scenario: Task available 10:00-11:00 AM
       - User A clicks at 10:00:00
       - User B clicks at 10:00:01
       - Both create UserTaskCompletion records (unique constraint allows ≠ started_at)
       - Both can proceed to proof submission (no exclusive ownership)
       - Both can complete (both marked as completed)
     
     Impact: Duplicate payouts, inventory overcounting, disputed results
     
     Standard Pattern (CPAlead):
       ✓ User clicks task → system acquires TaskLock(EXCLUSIVE, expires_at=+30min)
       ✓ Other users get "Task currently unavailable" message
       ✓ Lock released: on completion, on user abandon, or on expiry
       ✓ Expired locks auto-cleanup every 5 minutes

  ❌ NO TASK ASSIGNMENT SYSTEM
     Problem: All tasks are self-serve only
     Scenario: Publisher wants to assign premium task to VIP user
       - No mechanism exists to reserve task for specific user
       - Task goes to whoever completes it first
     
     Standard Pattern (OfferToro):
       ✓ Admin can create TaskReservation(user_id, task_id, reserved_until)
       ✓ Non-reserved users get 404 when querying reserved tasks
       ✓ Reservations can be time-limited or permanent
       ✓ Useful for: VIP users, affiliate exclusives, A/B tests

  ❌ NO CONCURRENT USER LIMIT
     Problem: Same task can be worked on by unlimited parallel users
     Scenario: High-value offer task (payout=$50, inventory=1000)
       - 5000 users click simultaneously
       - System creates 5000 UserTaskCompletion records
       - All 5000 try to complete (only 1000 should succeed)
       - Results in: disputed payouts, chargeback claims
     
     Standard Pattern (AdGate Media):
       ✓ MasterTask.max_concurrent_users = N (optional cap)
       ✓ Query counts active locks: WHERE task_id=X AND released_at IS NULL
       ✓ Reject new starts if active_count >= max_concurrent_users
       ✓ Enforces: "only 100 users working on this task at once"

  ❌ NO OWNERSHIP VALIDATION IN COMPLETION FLOW
     Problem: Any user can call complete_task() without verifying they own it
     Scenario: User A starts task, User B calls complete()
       - Current code: if user_id matches, completion accepted
       - BUG: If B spoofs request with A's user_id, completion awarded to A
       - NO LOCK verification prevents B from interfering
     
     Standard Pattern:
       ✓ complete_task(user_id) validates: user owns current TaskLock
       ✓ If lock missing/expired → OWNERSHIP_ERROR, no completion
       ✓ Prevents: session hijacking, multi-account abuse

  ❌ NO LOCK EXPIRY CLEANUP
     Problem: Stale locks accumulate indefinitely
     Scenario: User A starts task, browser crashes (no abandonment call)

       - Task marked as "in progress" but no one working on it

       ✓ cleanup_abandoned_locks() task runs every 5 minutes

  def acquire_task_lock(user_id, task_id, lock_timeout_seconds=1800):
      """Acquire exclusive lock on task for user."""
      expires_at = timezone.now() + timedelta(seconds=lock_timeout_seconds)
      
      try:
          lock = TaskLock.objects.create(
              task_id=task_id,
              user_id=user_id,
              lock_type='EXCLUSIVE',
              acquired_at=timezone.now(),
              expires_at=expires_at,
              lock_holder_worker=get_worker_id()
          )
          return (True, lock)
      except IntegrityError:
          # Another user holds exclusive lock
          existing_lock = TaskLock.objects.filter(
              task_id=task_id,
              lock_type='EXCLUSIVE',
              released_at__isnull=True
          ).first()
          
          if existing_lock and existing_lock.expires_at < timezone.now():
              # Expired lock - delete and retry
              existing_lock.delete()
              return acquire_task_lock(user_id, task_id, lock_timeout_seconds)
          else:
              # Active lock held by another user
              return (False, None)

  def release_task_lock(user_id, task_id):
      """Release lock (user abandoned or completed task)."""
      lock = TaskLock.objects.filter(
          user_id=user_id,
          task_id=task_id,
          lock_type='EXCLUSIVE',
          released_at__isnull=True
      ).first()
      
      if lock:
          lock.released_at = timezone.now()
          lock.save(update_fields=['released_at'])
          TaskEventLog.objects.create(
              event_type='LOCK_RELEASED',
              task_id=task_id,
              user_id=user_id,
              actor_type='USER',
              event_data={'reason': 'user_completion'}
          )
          return True
      return False

  def complete_user_task(user_id, task_id, proof_data):
      """Complete task - MUST validate lock ownership."""
      
      # Step 1: Verify lock exists and user owns it
      lock = TaskLock.objects.filter(
          user_id=user_id,
          task_id=task_id,
          lock_type='EXCLUSIVE',
          released_at__isnull=True
      ).first()
      
      if not lock:
          raise OwnershipError("User does not own lock for this task")
      
      if lock.expires_at < timezone.now():
          # Lock expired - release it
          lock.released_at = timezone.now()
          lock.save()
          raise LockExpiredError("Task lock has expired")
      
      # Step 2: Update lock version (optimistic locking)
      updated = TaskLock.objects.filter(
          id=lock.id,
          version=lock.version
      ).update(
          version=F('version') + 1,
          updated_at=timezone.now()
      )
      
      if updated == 0:
          raise ConcurrencyError("Lock was modified by another worker")
      
      # Step 3: Proceed with completion
      completion = UserTaskCompletion.objects.get(user_id=user_id, task_id=task_id)
      completion.status = 'COMPLETED'
      completion.proof_data = proof_data
      completion.completed_at = timezone.now()
      completion.save()
      
      # Step 4: Release lock on success
      release_task_lock(user_id, task_id)
      
      return completion

  def cleanup_abandoned_task_locks():
      """Remove expired locks (task remains unavailable to other users)."""
      
      # Find locks expired > 5 minutes ago
      expired_cutoff = timezone.now() - timedelta(minutes=5)
      
      expired_locks = TaskLock.objects.filter(

          expires_at__lt=expired_cutoff

      count = 0
      for lock in expired_locks:

          TaskEventLog.objects.create(
              event_type='TASK_LOCK_EXPIRED',
              task_id=lock.task_id,
              user_id=lock.user_id,
